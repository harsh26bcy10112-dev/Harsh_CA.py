1. Introduction

 In order to address the issue on a smaller scale, I have developed a Personal Finance Management System using Python.

The project is a command-line based application where an user can create an account and log in. Once logged in, a user can perform various operations related to calculation, monetary lending, savings, budget and expenses, and monthly expense tracking.

The main purpose of developing the project is to apply the concepts of Python learned throughout the course and implement them on a practical application.

2 .  Objectives

The objectives of the project are as follows:

1. To develop a simpler finance management application in Python

2. To provide account creation and login feature

3. To perform mathematical calculations

4. To record money lent or given to someone else

5. To track savings

6. To calculate budget, expenses

7. To manage monthly expenses

8. To apply the concepts of Python via a practical application

3. Project Description

The Personal Finance Management System is a menu-driven command-line application. The user is prompted to create an account first by providing the necessary information like name, username, password, etc. The user then logs in by providing the registered credentials. Once logged in, the user is redirected to the main menu where they can perform multiple actions by selecting the options provided.

The application makes use of the data structures like list, dictionary, and tuples to store data during run-time.

9. Data Structures Used

9.1 List

The list data structure helps in storing a multiple values together. The data structure can be used when there is a need to store expense-related data or savings-related data together.

9.2 Dictionary

The dictionary is helpful in storing key-value pairs together. The data structure can be used in the lending section to store a person’s name and the amount provided to them.

9.3 Tuples

The tuples data structure is similar to lists but are immutable in nature. The data structure can be used to store related values together. It can be used in the lending section to store the name of the person along with the amount lent.
